# 基于深度学习的 MDM2 抑癌靶点结合分子智能筛选与活性分层

> 围绕 p53-MDM2 相互作用这一经典肿瘤抑制轴，用深度学习筛选可调控 MDM2 的候选分子并区分其活性强度。

## 一、方法

- **模型**：图 Transformer（TransformerConv + 拉普拉斯位置编码）

- **输入**：分子图（原子节点 + 化学键边，RDKit 解析 SMILES 得到）
- **训练规模**：2500 条样本，2 类
- **标签协议**：rel
- **验证**：5 折分层交叉验证 × 3 随机种子 = 15 次独立训练
